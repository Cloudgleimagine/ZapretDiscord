>
> Некоторые антивирусные программы считают файлы WinDivert потенциально опасными либо относят их к хакерским инструментам. В результате файл удаляется и отправляется в карантин. Такое обнаружение обычно имеет название `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте папку zapret в исключения антивируса или отключите проверку PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы точно понимаете, как настроить исключения, предпочтительно добавить исключение. В противном случае рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и укажите поставщика, отличного от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * В Windows 11 Secure DNS можно включить непосредственно в параметрах системы — [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется
    * Владельцам роутеров Keenetic нужно включить в настройках опцию "Транзит запросов". При отключённом параметре Secure DNS на компьютере может работать некорректно

2. Скачайте zip- или rar-архив с [последнего релиза](https://github.com/Cloudgleimagine/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте пункт "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в каталог, в пути к которому нет кириллических и специальных символов

5. Запустите подходящий файл
    * Для поиска работающей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления стратегии в автозагрузку используйте **`service.bat`** -> `Install Service` -> *выберите нужную стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск подходит для проверки разных вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные операции:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск через services.msc</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб
  - **`Check Status`** — просмотр состояния обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** — включение или отключение обхода для игр и других сервисов, работающих с UDP и TCP-портами выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Текущее состояние показывается в скобках: включено или выключено.
  - **`IPSet Filter`** — изменение режима обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Этот пункт полезен при диагностике ресурса, который без zapret работает, а с ним — нет.  
  В скобках отображается текущий режим:
    - `none` — ни один IP не проходит проверку
    - `loaded` — проверяются IP из списка
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включение или отключение автоматического поиска обновлений
  - **`Replace active fakes`** — замена используемого фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>
  - **`Check for Updates`** — ручная проверка доступных обновлений
  - **`Run Diagnostics`** — поиск распространённых причин, из-за которых zapret может не запускаться или не работать.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord` — иногда это помогает при внезапном сбое приложения
  - **`Run Tests`** — запуск проверки стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/Cloudgleimagine/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - Найдите появившийся файл `hosts` и откройте его текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантирована. Если веб-версия не заработала, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/Cloudgleimagine/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии со временем могут переставать работать.**
> Вариант, который некоторое время успешно обходил блокировку, может перестать работать после его обнаружения.
> В проекте собрано много стратегий. Если готовые варианты не помогают, создайте новую стратегию на основе одной из имеющихся и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`

- Убедитесь, что нужный адрес есть в списке доменов или IP-адресов

- Проверьте остальные стратегии, включая **`ALT`**, **`FAKE`** и другие варианты

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/Cloudgleimagine/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и другие нужные данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; если программа найдёт ошибки, исправьте их, затем в конце выберите Y
- Удалите папку zapret
- Загрузите свежую версию со [страницы релизов](https://github.com/Cloudgleimagine/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива правой кнопкой мыши. При наличии пункта разблокировки внизу справа нажмите его, затем выберите применить и ОК
- Распакуйте архив в новую папку в корне диска, не используя пробелы и специальные символы
- По очереди запускайте разные скрипты `general` и проверяйте доступ к интернет-ресурсам. Если доступ не появился, закройте программу через значок замка на панели задач и попробуйте следующую стратегию
- После нахождения рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service` -> выбор нужной стратегии

### Не работает игра/приложение с включённым запретом

- Проверьте настройки `service.bat`: `Game Filter` должен иметь значение **`disabled`**, а `IPSet Filter` — **`none`**. В противном случае фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Инструкция по этому вопросу находится здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) на файлы с такими же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Определите имя службы командой в командной строке Windows, которую можно открыть через Win+R и `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) включён и настроен
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться
- Переберите остальные стратегии, особенно если раньше всё работало
- Дополнительные сведения смотрите в [#251](https://github.com/Cloudgleimagine/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить именно её
- В `service.bat` выберите `Run Diagnostics`, затем очистите кэш Discord
- Повторно проверьте приложение Discord и выясните, помогла ли очистка
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если Discord не открывается и в браузере, снова проверьте все стратегии. Возможна ситуация, когда YouTube работает на выбранной стратегии, а Discord — нет
- См. также [#252](https://github.com/Cloudgleimagine/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Cloudgleimagine/tg-ws-proxy)
- Также можно воспользоваться бесплатными MTProto-прокси, доступными в интернете

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них отдельно невозможно.

Обычно стоит сделать следующее:
- через `service.bat` обновить ipset и включить `Game Filter`
- если это не помогло, дополнительно включить `ipset any`

Учтите: режим `ipset any` может нарушить открытие множества сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/Cloudgleimagine/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/Cloudgleimagine/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети уже указан в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
