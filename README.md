>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как потенциально опасные или относящиеся к хакерским инструментам. В результате файл удаляется и переносится в карантин. В таком случае обнаружение обычно называется `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в список исключений антивируса или отключите проверку PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, лучше создать исключение. При сомнениях рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика, отличный от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` — Cloudflare может оказаться заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы — [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать неправильно или не настроиться

2. Получите zip- или rar-архив со [страницы последнего релиза](https://github.com/Cloudgleimagine/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и активируйте флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно не выполнять

4. Распакуйте архив в каталог без кириллических букв и специальных символов в пути

5. Запустите подходящий файл
    * Для поиска работающей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автозапуск, выберите **`service.bat`** -> `Install Service` -> *нужную стратегию*

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую для себя**

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** — включить или выключить обход для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  Состояние функции указано в скобках: включено или выключено.
  - **`IPSet Filter`** — переключить режим обхода сервисов, перечисленных в `ipset-all.txt`.  
  Это может пригодиться при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках отображается текущий режим:
    - `none` — IP-адреса не проходят проверку
    - `loaded` — IP проверяется на наличие в списке
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить используемый фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапной остановки работы приложения
  - **`Run Tests`** — запустить проверку стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare, Amazon и другие


## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не меняется

- При запуске стратегии отдельным BAT-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/Cloudgleimagine/zapret-discord-youtube/issues/522)

### Не удалось подобрать ни одну стратегию
- Откройте командную строку с правами администратора
- Выполните по очереди следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - Откройте от имени администратора файл `hosts` в созданной папке с помощью текстового редактора
  - Вставьте скопированное содержимое в конец `hosts` либо замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно записались.

#### Результат не гарантируется. Если способ не помог, попробуйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Cloudgleimagine/tg-ws-proxy) или одним из публичных прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Обнаружение используемого метода может привести к тому, что ранее рабочая стратегия со временем перестанет действовать.
> В репозитории доступно много стратегий обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из существующих и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и проверьте наличие ошибок

- Удостоверьтесь, что адрес нужного ресурса присутствует в списках доменов или IP

- Проверьте другие варианты (**`ALT`**, **`FAKE`** и прочие)

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/Cloudgleimagine/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезапустите устройство
- Откройте `service.bat` -> `Remove Services`
- Выполните `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их и в конце выберите Y
- Удалите старый каталог zapret
- Скачайте актуальную версию [со страницы релизов](https://github.com/Cloudgleimagine/zapret-discord-youtube) (`zapret-discord-youtube-...`)
- Откройте свойства архива правой кнопкой мыши. Если внизу справа доступна кнопка или флажок разблокировки, нажмите её, затем выберите применить и OK
- Распакуйте архив в новый каталог в корне диска, не используя пробелы, специальные символы и кириллицу
- Запускайте разные скрипты `general` и проверяйте доступность интернет-ресурсов. Если программа не помогает, закройте её через значок замка на панели задач и выберите другую стратегию
- После выбора рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при включённом zapret

- Проверьте в service.bat, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может повлиять на ресурсы, которые вы не планировали менять.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё отображается среди служб

1. Определите имя службы в командной строке Windows. Откройте Win+R, введите `cmd`, затем выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться
- Переберите остальные стратегии, особенно если выбранная раньше перестала работать
- Смотрите также [#251](https://github.com/Cloudgleimagine/zapret-discord-youtube/discussions/251)

### Не запускается или не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Для начала выясните, на какой стратегии открывается YouTube, и запустите её
- Откройте `service.bat` -> `Run Diagnostics` и очистите там кэш Discord
- Проверьте приложение Discord и выясните, помогла ли очистка кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, её можно использовать
- Если браузерная версия тоже недоступна, снова проверьте все стратегии. YouTube и Discord могут работать на разных вариантах
- Дополнительные сведения: [#252](https://github.com/Cloudgleimagine/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Cloudgleimagine/tg-ws-proxy)
- Также можно воспользоваться бесплатными MTProto-прокси, доступными в интернете

### Не запускаются игры

Игр существует много, поэтому проверить и исправить каждую из них невозможно.

Обычно стоит сделать следующее:
- через `service.bat` обновить ipset и включить `Game Filter`
- если это не решило проблему, дополнительно активировать `ipset any`

Учтите: режим `ipset any` может нарушить открытие большого числа сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если результат отсутствует, создайте обсуждение в разделе [Discussions](https://github.com/Cloudgleimagine/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет подходящей проблемы

- Опишите её [здесь](https://github.com/Cloudgleimagine/zapret-discord-youtube/issues)

## 🗒️Как добавить адреса других ресурсов

Расширить перечень адресов для обхода можно через следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети присутствует в `ipset-all.txt`, но конкретный домен этой сети фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
